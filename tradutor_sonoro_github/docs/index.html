RECURSOS

O que a versão 0.7 já faz

01

Dicionário treinável

Associe gravações a significados e mantenha várias amostras por palavra.

02

Reconhecimento acústico

Compara características do som utilizando MFCC e Dynamic Time Warping.

03

Tradução ao vivo

O microfone permanece aberto e a frase é montada conforme novos sons são detectados.

04

Previsão provisória

Durante um evento sonoro, o sistema pode mostrar uma hipótese antes da confirmação final.

05

Contexto

Frases já confirmadas ajudam a desempatar palavras acusticamente parecidas.

06

Execução local

O banco e as gravações permanecem no computador do usuário, sem servidor obrigatório.

INSTALAÇÃO

Executando no Ubuntu/Xubuntu

sudo apt update
sudo apt install -y python3 python3-venv python3-pip libportaudio2 portaudio19-dev
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python app.py
